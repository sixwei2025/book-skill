# Book-to-Skill 书籍智能化系统

> 把任何一本书变成可安装的AI Skill，同时生成公众号导流内容。

## 系统概览

```
[用户上传书籍PDF]
        ↓
[第一步] 深度解析 → 提炼方法论框架
        ↓
[第二步] Skill生成 → 写SKILL.md + 打包.skill文件
        ↓
[第三步] 导流内容 → 公众号标题 + 钩子文案 + 引导语
        ↓
[输出] .skill文件 + 公众号文案（可直接发布）
```

---

## 第一步：书籍深度解析

### 读取PDF

```python
# 用bash读取PDF文本
import subprocess
result = subprocess.run(['pdftotext', pdf_path, '-'], capture_output=True, text=True)
text = result.stdout

# 如果pdftotext不可用，使用PyMuPDF
import fitz
doc = fitz.open(pdf_path)
text = "\n".join([page.get_text() for page in doc])
```

读取后，按以下维度提炼：

### 提炼框架（必须提取）

**A. 书籍基本信息**
- 书名、作者、出版年份
- 核心主题（一句话）
- 目标读者

**B. 方法论骨架**
- 核心框架/模型（如：麦肯锡的MECE原则、稻盛和夫的阿米巴、《原则》的算法决策）
- 关键步骤（3-7步，可执行的动作）
- 核心概念术语表（5-10个）
- 金句/核心洞见（5-10条）

**C. 应用场景识别**
- 这本书解决什么问题？
- 典型使用场景（3-5个）
- 不适用场景（边界）

**D. Skill触发关键词**
- 用户说什么话时应该调用这个Skill？
- 从书籍内容反推触发词

## 第二步：生成Skill文件

### Skill命名规则
```
书名简写-method
例：
  《原则》→ principles-method
  《金字塔原理》→ pyramid-thinking
  《高效能人士的七个习惯》→ seven-habits
  《穷查理宝典》→ munger-thinking
```

### SKILL.md 模板

根据解析结果，生成如下结构的SKILL.md：

```markdown

  说"[触发词1]"、"[触发词2]"、"[触发词3]"时立即使用。
  帮助用户：[核心价值1]、[核心价值2]、[核心价值3]。
  适合[目标用户群体]在[典型场景]中使用。
---

# [书名] 方法论智能助手

> 基于《[书名]》—— [作者]

## 核心框架

[从书中提炼的核心模型，用结构化方式呈现]

## 使用流程

### 第二步：[步骤名]

|------|------|------|
```

## 第三步：生成公众号导流内容

每本书自动生成三套导流内容：

### 内容A：公众号文章标题（5个备选）

按爆款公式生成：
- 数字型：「我把《[书名]》喂给AI，它给了我一个[X]步决策框架」
- 对比型：「普通人读《[书名]》记笔记，我用AI把它变成了每天可以用的工具」  
- 好奇型：「《[书名]》被我做成了一个AI智能体，用过的人都说香」
- 场景型：「遇到[书中核心问题]，我现在直接问AI——它已经把《[书名]》吃透了」
- 价值型：「免费领：《[书名]》AI版，帮你把书中方法论用起来」

### 内容B：推文钩子文案（开头3段）

```
[第一段：制造场景共鸣，100字以内]
你有没有这种体验：书买了，也读了，但两周后脑子里什么都剩不下？

[第二段：引出解决方案，100字以内]  
我用AI把《[书名]》变成了一个Skill——它不只会告诉你书里写了什么，
它会在你遇到[核心问题]时，用[作者]的框架帮你分析、给你方案。

[第三段：社会证明+号召行动，100字以内]
这个Skill现在免费开放，文末扫码安装，下次遇到[典型场景]，
直接问它，比你自己翻书快10倍。
```

### 内容C：评论区引导语（3个版本）

```
版本1（简短）：
「想要《[书名]》Skill的，评论区留言「[书名简称]」，自动回复安装链接」

版本2（增加紧迫感）：
「前100名留言「[书名简称]」的朋友，私信发你Skill安装包（限时）」

版本3（带价值锚定）：
「我把这本书变成Skill花了4小时，你只需要留言「[书名简称]」，30秒安装完」
```

## 打包与输出

```bash
# 打包Skill
python -m scripts.package_skill /path/to/[book-skill-folder]

# 输出两个文件：
# 1. [bookname]-method.skill  → 用户安装文件
# 2. [bookname]-wechat.md     → 公众号导流内容
```
