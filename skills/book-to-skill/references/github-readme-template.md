## 为什么要有书籍Skill？

你买了书，读了书，两周后什么都记不住。

书籍Skill解决这个问题：**它把书的方法论变成一个AI工具，遇到问题直接问它，它用书里的框架帮你分析。**

## 如何安装

1. 下载 `.skill` 文件
2. 在 Claude 中打开「技能设置」
3. 点击「安装本地Skill」，选择文件
4. 完成！直接开始对话
